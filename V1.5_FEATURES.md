# TVA v1.5 — missing feature implementation

Implemented from the requested feature gap list:

1. Contacts sync
2. Continuous location tracking (visible foreground service)
3. Usage stats / app usage insights
4. Notification insights (package + count only, never notification text)
5. Camera Vision Mode
6. Background continuous sync (visible foreground service)
7. AI Chat interface with server-side conversation memory

Safety/Android behavior:
- No hidden camera.
- No hidden background collection.
- Foreground services show persistent Android notifications.
- Each sensitive category remains permission/consent gated.
- Camera is user-triggered only.
- Contact sync is explicit and replace-on-sync per device.
